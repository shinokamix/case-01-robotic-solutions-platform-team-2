# Сессия вопросов и ответов

Каталог содержит локальную машинную расшифровку записи `Город 1. Департамент предпринимательства + ФЦ БАС.mp4`.

Сам MP4 не добавлен в репозиторий из-за размера 2,5 ГБ. Его SHA-256 указан в `content.md`.

| Файл | Назначение |
| --- | --- |
| `content.md` | Читаемая расшифровка, сгруппированная по темам и таймкодам |
| `transcript.srt` | Субтитры с точными временными интервалами |
| `transcript.raw.json` | Необработанный результат Whisper с сегментами и временными метками слов |
