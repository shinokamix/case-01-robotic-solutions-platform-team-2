# Платформа подбора роботизированных решений

Исходные материалы находятся в [`artifacts/`](artifacts/).

Продуктовая и техническая проработка находится в [`docs/product-discovery/`](docs/product-discovery/README.md).

## Команды

Запускайте команды из корня репозитория:

```bash
make dev       # разработка
make build     # сборка
make lint      # линтер
make check     # линтер и сборка
```

Команды веб-приложения:

```bash
make web-dev
make web-build
make web-lint
make web-check
make web-knip
make web-preview
```
