# Платформа подбора роботизированных решений

## Зачем нужны эти документы

Этот раздел содержит краткую выжимку конкурсных материалов и описывает предлагаемое решение. Он нужен для согласования продукта перед созданием OpenSpec.

Дата анализа: 15 сентября 2026 года.

## Что нужно построить

Платформа помогает подготовить предварительную оценку роботизации. Пользователь задает параметры объекта, получает подходящие решения и сравнивает текущий процесс, покупку оборудования и RaaS.

Платформа отвечает на пять вопросов:

- какие решения подходят.
- почему они подходят или не подходят.
- сколько оборудования потребуется.
- сколько стоит каждый сценарий.
- какие данные нужно проверить перед пилотом.

Расчет не заменяет обследование объекта, инженерный проект, проверку поставщика или финансовый аудит.

## Предлагаемый MVP

Полный сценарий охватывает внутрискладское перемещение паллет. Он включает ввод данных, подбор решений, экономический расчет, анализ чувствительности, 2D-имитацию и PDF-отчет.

Для аэропорта и медицинского учреждения MVP показывает отдельные формы и подходящие типы решений. Полная экономика и имитация для этих объектов появятся позже.

## Главные выводы

- Предоставленных данных достаточно для демонстрации, но каталог нужно нормализовать и дополнить ТТХ.
- Текущих данных недостаточно для обучения рекомендательной модели.
- Критические ограничения нужно проверять правилами. ML не должен отклонять решения.
- Каждый расчет должен хранить версии данных, правил и формул.
- Демонстрация должна работать без внешних сайтов.
- Несколько продуктовых и финансовых решений еще требуют подтверждения.
