# Платформа подбора роботизированных решений

## Зачем нужны эти документы

Этот раздел отделяет исходные материалы и требования ТЗ от решений команды. Такое разделение нужно до создания OpenSpec.

Дата анализа: 15 сентября 2026 года.

## Документы

1. [Выжимка исходных материалов](01-artifact-summary.md) описывает переданные файлы, данные, требования, критерии, противоречия и пропуски.
2. [Требования и продуктовая рамка из ТЗ](02-product-concept.md) фиксирует обязательные функции, допустимые варианты и решения, которые ТЗ оставляет команде.
3. [Решения и дорожная карта](03-decisions-and-roadmap.md) содержит решения команды, границы pre-MVP и MVP, допущения и план реализации.
